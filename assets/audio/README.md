# Audio Assets for Jaagrat

This directory holds the high-decibel alert audio files:

- `warning_chime.wav`: Soft warning chime (Level 1) before regional speech alert.
- `emergency_siren.wav`: High-frequency piercing siren / horn (Level 2) that cuts through engine rumble and highway wind noise.

The regional voice prompts ("Attention, please focus on the road") are synthesized on-device in real-time using `flutter_tts` in:
- Hindi (`hi`)
- Kannada (`kn`)
- Tamil (`ta`)
- Telugu (`te`)
- Marathi (`mr`)
- English (`en`)
